# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-10-11

### Added

- GLM-5.3-Flash creative genome sequencing and strategy mutation.
- glm-image material generation.
- Five-dimensional Loop QA with actionable rejection reasons.
- BYOK and server-funded access modes.
- Vercel deployment configuration and long-running function support.
- Structured handling for rate limits, upstream non-JSON responses, and
  deployment-platform interruptions.

### Security

- Removed hard-coded admin credentials from client and server source.
- Added server-only access-control environment variables.
- Added secret-safe Git and Vercel ignore rules.
- Added security policy and CI validation.
